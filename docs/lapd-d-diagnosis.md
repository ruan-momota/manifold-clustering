# Iris 在 D=2、3 时失败的原因

## 结论

当前输入和参数下，较高 D 的局部结构筛选后连接太少，无法满足官方去噪的覆盖要求；官方代码又没有处理阈值候选耗尽的情况，最终发生数组尺寸错误。这不表示 LAPD 不支持 D=2、3，也不是一次可用于比较 ARI 的成功运行。

依据是远程错误日志、固定版本的官方源码，以及本地对同一批 Iris 向量的几何检查。没有改动官方源码或实验参数。

## 本地检查结果

输入仍为 ID 61 的 `embeddings_scaled`，150 个样本，147 个不同向量；带宽为 10、半径为 0。

| D | 保留的局部结构数 | 连接部分数 | 最大部分的结构数 | 位于至少 50 个结构的部分中的比例 | 这些部分最多覆盖的样本数 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 1 | 951 | 2 | 634 | 100% | 150/150 |
| 2 | 415 | 39 | 133 | 63.3735% | 101/150 |
| 3 | 65 | 24 | 16 | 0% | 0/150 |

“局部结构”在 D=1 时是连接两个样本的边，D=2 时是三角形，D=3 时是四个样本组成的结构。只有共享相应面的结构才相连。

检查脚本按官方构建规则生成结构，然后把所有共享面的连接都加入图中。它没有计算角度权重或运行完整聚类，因此给出的是连接和覆盖的上限。Python 与 MATLAB 的距离数值及并列近邻排序可能有差别；但本地 D=2 的 63.3735% 和 D=3 的 0% 都与远程警告中的数字吻合，为当前解释提供了直接支持。

复核命令：

```powershell
.\.venv\Scripts\python.exe scripts/diagnose_lapd_geometry.py
```

输出为 `results/lapd_d_geometry.csv`。这个脚本只检查 Iris 的当前设置，不是 Python 版 LAPD，也不用于计算聚类分数。

## 为什么较高 D 更容易断开

[官方 buildsimplex.m](https://github.com/HYfromLA/LAPD/blob/d678a0baa2a4d9b0134ff1719c80c42e78eda108/Auxiliary/buildsimplex.m) 在 D=1 时不做形状筛选。D>1 时，只保留最长边与最短边的比值不超过阈值的结构；默认阈值在 D=2 时为 1.25，D=3 时为 1.40。

同样使用 10 个近邻，D=1 可以连接更多样本；D=2、3 不仅要求形成合格结构，还要求结构之间共享面。当前检查显示，这两项要求导致图碎成了许多小部分。重复向量也会使某些候选结构含零长度边并被排除，但尚未单独量化重复向量对本次失败的贡献。

## 为什么最终出现数组尺寸错误

[官方 denoise.m](https://github.com/HYfromLA/LAPD/blob/d678a0baa2a4d9b0134ff1719c80c42e78eda108/Auxiliary/denoise.m) 使用 `SKNN=floor(10*log(150))=50`。这里的近邻是局部结构之间的路径近邻，不是样本的欧氏近邻。

如果一个连接部分不足 50 个结构，程序把对应的第 50 近邻距离设为 `Inf`。去噪只保留距离小于阈值的结构，因而即使阈值提高到 `Inf`，这些结构也不会通过：`Inf < Inf` 为假。

程序同时要求保留的结构覆盖至少 95% 的样本，即 Iris 至少 143 个。D=2 的可用部分最多只能覆盖 101 个；D=3 没有达到 50 个结构的部分。当前图上，这个覆盖目标无法达到。

于是程序继续寻找更大的阈值。关键两行是：

```matlab
cutoff = Ths(find(Ths > cutoff, 1, 'first'));
rowsTokeep = knndistances < cutoff;
```

当没有更大的候选值时，`find` 返回空数组，`cutoff` 也变为空，下一行报尺寸错误。根据源码和远程报错位置，这是直接原因的判断；远程尚未保存报错瞬间的变量，因此没有实测最后一次 cutoff。初始自动阈值还会用包含 Inf 的距离估计拐点，这也可能使阈值提前变成 Inf 或 NaN，需要远程变量记录才能确定具体路径。

警告文字也有问题：它声称打印的是无穷距离比例，实际打印的是距离小于 5 的比例。本次两侧权重为角度距离，有限路径距离在该范围内，因此打印值对应可用部分比例，不能按“无穷比例”理解。

## 下一步如何处理

单纯在阈值耗尽时跳出循环，只能避免崩溃，不能让不足的覆盖率变好。先保留这两次失败，随后可以另开一组诊断配置，尝试放宽形状筛选或扩大邻域，观察结构连接和覆盖是否改善；保持 D 明确记录，一次只改一个参数。

这些运行应与当前“其他显式参数固定”的 D 检查分开记录。参数改变后能否提高 ARI 仍需实际运行，不能从图更连通直接推出准确度更高。
