# WMC 接入 ZEUS 的初始结果

已在 CPU 上完成全部 34 个 OpenML 数据集的 L-WMC 实验。所有样本均有预测，实际输出组数均等于请求组数；保存的标签、样本索引和预测数量已逐数据集核对，CSV 中的 ARI 已从保存的预测重新计算核对。

## 实验设置

代码仍保留在 [08_wmc_zeus_openml.ipynb](../notebooks/08_wmc_zeus_openml.ipynb)，尚未抽取到 `.py`。使用已有的 `embeddings_scaled`，不增加降维、白化或逐样本归一化；真实类别数只用于最终分组和评分，不参与重建或参数选择。

统一参数为 `gamma=50`、`eta=20`，只使用线性距离权重和源码已有的 `lasso_lars` 路径。工作集大小为 100，最多更新 40 次，每行最多保留 50 个非零重建系数。系数逐行归一化、取绝对值并对称化后，使用 scikit-learn 谱聚类，`random_state=42`、`n_init=100`。全部数据集采用相同设置，没有按 ARI 选择参数。

核心计算参考本地 `vendor/WMC/NeurIPS2024-Manifold/utils/selfrepresentation.py`。该副本存在修改，文件 SHA-256 为 `b7ea8bd7810ba17a1a29d75b2690311117372099f610634405cb2356bdaa0a8a`。ID 61 和 ID 14 的连接矩阵已与本地原函数在相同条件下直接比较，最大绝对差均为 0。最终谱聚类入口与原实验脚本不同，因此这里报告的是接入 ZEUS 的初始实验，不是论文数值复现。

## 主要结果

三种方法均在全部 34 个数据集上有完整预测：

| 方法 | 34 个数据集的平均 ARI |
| --- | ---: |
| ZEUS + K-means | 0.573642 |
| ZEUS + CPP | 0.498960 |
| ZEUS + L-WMC | 0.014943 |

L-WMC 在全部 34 个数据集上均低于 K-means。这里用 `1e-6` 作为近似相同的阈值，与现有 CPP 比较规则一致。WMC 生成连接矩阵合计约 258 秒，最终聚类合计约 10 秒。

与 LAPD 的“提供 K”实验比较时，四种方法在同一批 27 个预测完整的数据集上重算均值：

| 方法 | 同批 27 个数据集的平均 ARI |
| --- | ---: |
| ZEUS + K-means | 0.600688 |
| ZEUS + CPP | 0.510208 |
| ZEUS + LAPD，提供 K | 0.326491 |
| ZEUS + L-WMC | 0.017957 |

LAPD 提供 K 不保证实际输出恰好 K 个组。其余 7 个 LAPD 已知组数运行因预测不完整，没有进入四方法均值；逐数据集表仍保留这些数据集，LAPD 分数为空。

## 连接图与数值问题

34 张图中有 **33 张不连通**，而且独立部分数均超过目标类别数；独立部分数最多为 594。只有 ID 56 的图连通，但它的 ARI 也仅约 0.035。这说明连接图断开是普遍问题，但不能把所有低分都归结为这一点。

此前的原源码核对显示，ID 61 分成 36 个部分，目标为 3 类；ID 14 分成 410 个部分，目标为 10 类。它们的每个样本通常只选中一个重建样本，使连接图形成很多小块。图不连通并不表示矩阵无效；当独立部分远多于目标组数时，最终分组可能对数值计算敏感。重新执行 notebook 后，Iris 的 ARI 从此前约 0.013 变为本次约 0.009，因此本结果按本次运行保存，不混用此前试跑值。

运行还出现 Lasso 候选向量退化、删除候选及提前停止的数值警告。这些数据集有完整预测，不代表每个重建问题都已得到理想的数值解。当前没有切换求解器、修改参数或自动补边，警告与运行记录可在 notebook 中查看。

下一步适合先研究惩罚强度、输入尺度与连接稀疏程度的关系，并核对求解器的数值表现。当前结果只能说明这一组固定设置在 ZEUS 缩放向量上表现较差，不能据此评价 WMC 的所有设置。
