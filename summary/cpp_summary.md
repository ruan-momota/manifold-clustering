# CPP 接入 ZEUS 的初始结果

完整图像复现阶段暂时跳过。当前已在 CPU 上完成全部 34 个 OpenML 数据集的 ZEUS + CPP 实验，使用保存的 `embeddings_scaled`，每个数据集独立训练；真实类别数仅用于谱聚类组数，标签不参与训练。

初始参数统一设为：输入 512 维、隐藏层 4096 维、输出 128 维、训练批量 128、训练 5 轮，其中第一轮用于初始化；随机种子为 42。网络、损失和关联计算使用官方 CPP commit `cb39bdc65f346b4cb5950d14af2e393a5f6a3566`。预测时对称化样本关联矩阵，使用 scikit-learn 谱聚类，K-means 初始化次数为 100。实际代码与运行输出见 [notebook](../notebooks/07_cpp_zeus_openml.ipynb)。

| 34 个数据集 | 平均 ARI |
| --- | ---: |
| ZEUS + CPP | 0.499 |
| ZEUS + K-means | 0.574 |

CPP 在 12 个数据集上更高、6 个近似相同、16 个更低；差异绝对值不超过 `1e-6` 视为近似相同。[逐数据集结果](../results/cpp_zeus_openml.csv)保留评分、训练和预测耗时。全部训练约 95 秒，预测约 24 秒。所有样本均有预测，预测数量与原始样本数一致；保存的标签和样本索引与 ZEUS 缓存逐项一致。

与 LAPD 的“提供 K”实验比较时，只使用三种方法均有完整预测的同一批 27 个数据集：

| 方法 | 同批 27 个数据集的平均 ARI |
| --- | ---: |
| ZEUS + K-means | 0.601 |
| ZEUS + CPP | 0.510 |
| ZEUS + LAPD，提供 K | 0.326 |

LAPD 的“提供 K”不保证实际输出 K 个簇；CPP 本次预测均输出请求的组数。以上比较对应当前统一参数与单个随机种子，不代表 CPP 或 LAPD 经参数研究后的表现。
